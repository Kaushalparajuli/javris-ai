# How to run a competitor scan

1. Find 4–6 direct competitors. Prefer the vendor's own
   pricing page over review sites.
2. For each one, record: plan names, monthly price,
   free tier, top 3 features, target customer.
3. Fill templates/comparison.md. Leave a cell blank rather
   than guess; add a note saying why.
4. Close with "What changed since last scan" if a previous
   report exists in the task folder.

## Sources
Cite every price with a link and the date you checked it.
